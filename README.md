# Ligas Francesinha Manager

I have a football league with friends, called 'Ligas Francesinha' (the app should be called ligasfrancesinha). We are 14 players (some years we were 12 6v6). Every week we get random 7v7. Every one in the winning team wins 3 points. Every body that went to the game gets 1 point as well. Draw is 1 point for every player that played. I should be able to get the teams each week, and input the results each week.
